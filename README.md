# Justin Kirkwood — South Florida Real Estate Blog (JUSTINAPP)

A fully static, AI-crawlable real estate blog engineered for **Generative Engine Optimization (GEO)** — so AI assistants (ChatGPT, etc.) and search engines associate **Justin Kirkwood, Luxe Properties** with being *the best agent* in each South Florida neighborhood, turning organic + AI search into a lead funnel.

## How it works
Everything is generated by one script, `generate.py`, from `config.json` (agent + neighborhood data) and `data/posts.json` (the post archive).

```bash
python3 generate.py --build      # rebuild the whole site from existing data
python3 generate.py --new-post   # publish today's neighborhood-trend post + rebuild
```

A scheduled task (`justinapp-daily-post`, 7am daily) runs `--new-post` automatically, so a fresh hyper-local post publishes every morning. Each post rotates through neighborhoods (Coral Gables, Pinecrest, Cutler Bay, Kendall, South Miami) and content angles (market update, home value, best time to sell, condo vs. townhome, school guide, seller playbook).

## What makes it rank for "best agent in [neighborhood]"
- **Entity signals:** `RealEstateAgent` schema.org markup on every page tying Justin to the brokerage, award, phone, and areas served.
- **FAQ schema:** every page answers "Who is the best agent in [neighborhood]?" with Justin's name — the format AI assistants quote directly.
- **Hyper-local, niche content:** one neighborhood at a time, not "Miami realtor" (per the GEO playbook).
- **Article schema, canonicals, sitemap.xml, robots.txt** — clean, crawlable static HTML (no JS required to read content).

## Lead funnel
Every page has CTAs to a `/contact.html` lead form. Submissions are saved in the browser and open a prefilled email to Justin. To connect a CRM/form service, edit `submitLead()` in `assets/main.js`.

## Before you publish
Edit `config.json` to replace the placeholders:
- `agent.phone` / `agent.phone_href` — currently `(305) 555-0100`
- `agent.email` — currently `justin@luxeproperties.com`
- `site.domain` — set to your real domain
- Drop a real headshot at `assets/justin.png` (a branded placeholder is there now).

Then run `python3 generate.py --build`.

## Chat assistant ("Chat with Justin")
Every page has a chat bubble (bottom-right). Out of the box it runs a built-in **rule-based assistant + lead capture** — no API key, works on a pure static host. It answers "who's the best agent in [neighborhood]?" with Justin, talks buying/selling/valuations, and captures name + phone/email as a lead (saved locally and emailed to you).

### Upgrading to real AI (running an API on it)
A static site can't safely call an AI API directly — the key would be exposed in the browser. The fix is a tiny serverless backend that holds the key. See `serverless/chat-worker.js` (a Cloudflare Worker; free tier is plenty). Deploy it, add your `ANTHROPIC_API_KEY` as a secret, then set `"apiEndpoint"` in `chat_widget()` inside `generate.py` to the worker URL and rebuild. The widget automatically uses real Claude responses and falls back to the rule-based bot if the endpoint is ever down. (Swap the fetch block for OpenAI if you prefer.)

## Deploy
It's plain static files — host free on Netlify, Vercel, GitHub Pages, or Cloudflare Pages. Just point the host at this folder. (Cloudflare Pages pairs nicely with the chat Worker.)
